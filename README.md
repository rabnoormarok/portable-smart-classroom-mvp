# 🚀 Portable Smart Classroom – MVP

## 📌 Problem Statement
Many lecture halls on campus lack projectors and smart teaching equipment. This limits lecture quality, reduces student engagement, and makes it difficult to present digital content effectively.

## 💡 MVP Solution
A low-cost, plug-and-play smart classroom solution that uses a portable projector and wireless screen-casting technology to enable lecturers to present digital content in any classroom.

## ⚙️ Core Features
- Wireless screen casting from laptop/mobile devices
- Portable projector support
- Quick setup with no permanent infrastructure

## 🧠 Tech Stack
- Hardware: Portable projector, HDMI / wireless dongle
- Software: Web-based screen sharing / Android casting
- Connectivity: Wi-Fi / Mobile hotspot

## 🎯 Impact
- Improves lecture quality
- Increases student engagement
- Affordable and scalable for campuses
